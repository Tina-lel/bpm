<p align="center">
A <s>fully functioning</s> package manager for GNU/Linux written in bash
</p>

> [!IMPORTANT]
> No generative AI of ANY KIND was used for this project!

## Dependencies

```plaintext
bash
curl
tar
gzip
```

## Installation

```shell
git clone --depth 1 https://github.com/Tina-lel/bpm.git
cd bpm/
 ./install.sh
```

## Usage

```plaintext
usage: bpm <operation> [...]
operations:
    bpm add     [package(s)]
    bpm del     [package(s)]
    bpm update
    bpm upgrade
    bpm config
    bpm clean
    bpm depclean
    bpm search  [package]
    bpm info    [package]
    bpm list
    bpm index   (package)
    bpm help
    bpm version

```
